## 1 设置

外层 5 折（分层，种子 11）；列选择、中位数填补、q 估计都只在当前训练折内拟合。配置：M3 基线、M4 原生 NaN、M5L（仅标志 + LR）、M5T（仅标志 + HGB），以及 C/B 在 α∈{0.25, 0.5, 1.0} × 3 个遮蔽种子。评价条件 S0 / S1 10% / S1 30%。区间用折内按行重采样的池化 bootstrap（1,000 次）。

数据：1,567 行、590 列、104 正类（6.6%）；整体缺失 4.54%，52 列零缺失，无全空列，单列最高 91.2%。

## 3 区间（折内重采样，9 个比较）

九格里只有一处区间不含 0：α=0.5、S1 10% 时 **B−A0 = −0.026 [−0.050, −0.002]**。

其余差值都在 ±0.02 上下且跨 0，例如 α=0.25 时 C−B 在 S0 为 −0.005 [−0.037, +0.022]、S1 30% 为 +0.012 [−0.010, +0.046]。

## 4 怎么读

1. **SECOM 上 C 既不显著更好也不显著更差**，与 APS 的强负向不同。原因在数据：|gap|>0.1 的列只有 8 个（APS 64 个）、最大缺口 0.172（APS 0.747），仅标志 HGB 的 AUROC 只有 0.5856（APS 0.9765）。没有可利用的耦合，就没有可观的代价。
2. **α=1 也没有坍塌**：C 的 S0 AP 是 0.1581，基线 0.1749，差 0.017。这与 APS 上 0.86→0.12 的坍塌形成对照，进一步支持"代价来自删除集中打在少数列的正类观测上"这一机制——SECOM 没有这样的列。
3. **B 并非处处更好**：α=0.5 时 B 在 S0（0.1589）低于 C（0.1783）与基线，且在 S1 10% 上显著低于基线。这是真实结果，正文里如实报告，不用"B 从不更差"去概括所有数据。
4. **单折不可读**：单折只有约 21 个正类。基线 M3 的 S0 逐折 AP 是 0.126 / 0.217 / 0.268 / 0.205 / 0.203，最高与最低差一倍以上；C/B 各折×3 个遮蔽种子的散布更宽（如 B 0.25 的 S0 从 0.130 到 0.314）。`fold_ap_spread` 记录了全部逐折值，不可拿单折排序下结论。

## 5 与 pilot 的差别

pilot 只有 α∈{0.25, 0.5}、两个条件、重复次数少，结论是"C 与 B 差别在 ±0.03 内"。正式版把 α 网格补到 1.0、条件补到三个、区间改为折内重采样，结论不变：差别小、方向不一致、没有可检出的效应。唯一新增的显著项是 B 在 α=0.5/S1 10% 下略低于基线。
