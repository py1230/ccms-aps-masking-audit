## 为什么需要重建

复现件用 `Mv = hstack([imp.transform(ev), isnan(ev)])` 生成评价矩阵，其中：

- `imp` 由该划分的训练行拟合；
- `ev = build_eval_inputs(Xva)["S1_30_101"]`，即对验证集再做一次 30% 的单元格遮蔽（seed=101）。

这两样都没落盘。重建后，加载 30 个模型跑出的概率与已存概率差 **0.0**，说明重建的输入与当时完全一致。

## 三种掩码怎么区分

```
native = isnan(Xva)                      # 原始数据本来就缺的格
merged = isnan(ev)                       # S1_30_101 施加之后的缺失
added  = merged & ~native                # 本次追加删除的格（只落在可见格上）
```

读取示例：

```python
import numpy as np
z = np.load("rebuilt/eval_masks_s11.npz")
shape = tuple(int(v) for v in z["mask_shape"])
n = shape[0] * shape[1]
native = np.unpackbits(z["native_bits"])[:n].reshape(shape).astype(bool)
added  = np.unpackbits(z["added_bits"])[:n].reshape(shape).astype(bool)
merged = np.unpackbits(z["merged_bits"])[:n].reshape(shape).astype(bool)
print(native.sum(), added.sum(), merged.sum())
```
