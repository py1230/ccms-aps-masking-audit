## 对随包核验说明的四项修正

1. **概率吻合不能证明历史输入矩阵唯一相同。** 多个输入可能产生相同预测；本次能核对的是由现有原始数据、指定规则得到的矩阵与事后记录相同，历史矩阵本身仍未提供。
2. **原核验脚本的退出码 0 不充分。** 原脚本计算了 `m3_match` 却未用于判定；若部分概率、哈希或映射比较失败，仍可返回 0；CSV 映射仅核对每划分的 C/2026 组，训练掩码主要比较记录中的哈希字符串。新增严格脚本覆盖所有 30 组、实际掩码位、矩阵哈希及独立历史 AP 文件，失败返回非零。另用“修改 M3 预期哈希并重新生成清单”的隔离副本测试，脚本准确拒绝且返回 1。原收件未修改。
3. **完整命令现有抄录，原始平台投影未随包。** 抄录共 1,879 字符，脚本正文 1,811 字节，与历史入口脚本逐字节一致；前 500 字符与终端元数据一致。这补齐了命令内容，但不独立认证原聊天提取过程或时间线。
4. **历史退出码 0 属于启动器。** 完整命令使用 `nohup python3 ... &` 后输出 `started`；外层终端退出码不能视作后台训练 Python 进程的独立退出记录。日志末尾 `SEED_DONE` 和 30 条结果另行支持脚本走到完成标记。
