Inspect the acquisition plan without any network operation:

```bash
python scripts/acquire_data.py aps
python scripts/acquire_data.py secom
python scripts/acquire_data.py hydraulic
```

To download and extract only fingerprint-verified members:

```bash
python scripts/acquire_data.py aps --download
python scripts/acquire_data.py secom --download
python scripts/acquire_data.py hydraulic --download
```

For a previously downloaded archive:

```bash
python scripts/acquire_data.py secom --archive /path/to/secom.zip --output /path/to/new/secom
```

The output directory must be new. `data/raw_member_fingerprints.json` contains SHA-256 values of the historical local files actually used in this project. The downloader aborts on a changed member fingerprint; do not rewrite the expected hash to make a new dataset appear historically identical. A download may fail if the repository changes or access is interrupted. The local acquisition smoke test verified the already downloaded SECOM ZIP; this stage did not redownload all three datasets.

The APS files are the official training and test CSVs, including the train/test distinction; do not replace them with a newly randomised split. SECOM labels include timestamps; temporal evaluation uses the archived chronology and windows. Hydraulic feature extraction and target/group construction are in the frozen hydraulic source snapshot. A downloaded raw file alone is not sufficient to reproduce every historical training run: the corresponding protocol, indices, configuration and environment are also needed.

The simulation data are generated by the preserved scripts, with separate mechanisms and independent seed sets. The portable simulation entries regenerate the complete synthetic matrices, masks, models and predictions from the original seeds. The package includes current source, configurations and fresh acceptance evidence. The original full 60-seed model archives are retained locally and can be regenerated with the documented full schedules. Refer to `TRAINING.md` and `RESULT_MAP.md` for the executed acceptance scope.
