## 7. 科学表述边界：FAIL（主估计量正确，附加区间字段需说明）

### 已通过部分

summary 第 7 行与脚本第 131–144 行的主 `ci95` 一致：先每个 draw 的折内 C−B 差，S1_30 先平均三个条件副本，再平均五折，最后对 20,000 个折均值取 2.5/97.5 百分位。不是将全部样本合池后算 AP，也不是先跨折拼概率。summary 未报告 p 值、未把重采样符号比例命名为显著性检验，也未给因果结论。

四格主区间均跨 0。只能据此描述该固定预测、固定分折和固定条件副本下的重采样区间；不能由此证明零效应，也不覆盖重新训练、重新划分、重新选 α 或重新生成遮蔽条件的全部不确定性。

### 未通过部分：`ci95_transposed`

生产脚本第 145 行实际计算 `interval(d.mean(axis=0))`。`d` 为 (20000,5)，因此先把 20,000 次重采样平均掉，剩 **5 个折的 bootstrap 均值**，再对这五个值取分位。实测产物确实如此：

| 格 | ci95_transposed 实际值 |
|---|---|
| fixed / S0 | [-0.006236252286080152, 0.020119222040486787] |
| fixed / S1_30 | [-0.015524332246001665, 0.018564111003293554] |
| selected / S0 | [-0.020889376696468138, 0.005047704896375412] |
| selected / S1_30 | [-0.028786021978098698, 0.0003537666182742243] |

它与代码**数值一致**，但不符合 summary 所声明的目标量区间，也不能仅以 `ci95` 的名字当作另一种有效 95% 置信区间使用。现存材料未解释其诊断用途。应由生产者删除该多余字段，或更名并明示“对五个折 bootstrap 均值的描述性分位数，非主置信区间”；本复核不代为修改。

`draw_mean_se` 实际为 draw 均值分布的 SD/√20000，适合解释为 bootstrap 均值的 Monte Carlo 标准误，不能当作原始 ΔAP 的抽样标准误或区间端点精度；当前材料未明示，宜一并补充。
