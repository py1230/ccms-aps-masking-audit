# Findings（本次重跑，2026-11-12）

四条，均绑定本目录实际产物与输入哈希；不含未执行或未验证的推断。

## 1. 重跑口径与原归档逐一吻合，这是"同一套计算"而非近似

前 1,000 次 draw 复算出的四格点估计与 95% 区间，与 `原件补件_2026-11-11/…/secom_summary.json` 的 `paired` **差值全为 0.0**（点估计、区间上下限、五折点估计均相等）。

- 边界：归档没有保存逐次差值数组，所以这是「汇总一致」，不能写成与历史逐次数组逐值一致。

- 来源：`exports/secom_boot20k_validation.json`（`all_pass: true`），`logs/run.log` 的 `[validate]` 四行。
- 含义：本次实现可以代表原口径；不能反过来说"找到了原运行"。

## 2. 四格 ΔAP 全部跨 0，SECOM 上区分不出 C 与 B

| 格 | ΔAP | 95% 区间 | ΔAP<0 占比 |
|---|---|---|---|
| α 固定 0.25 · S0 | +0.011272 | [−0.012829, +0.030606] | 0.199 |
| α 固定 0.25 · S1_30 | +0.003076 | [−0.010893, +0.019856] | 0.283 |
| 验证集自选 α · S0 | −0.004358 | [−0.028410, +0.020135] | 0.636 |
| 验证集自选 α · S1_30 | −0.010199 | [−0.023841, +0.002893] | 0.933 |

分母与口径：5 折 × 每折 312–314 个测试样本（合计 1,567，正类 104），20,000 次折内分层重采样，配对比较同一折同一测试行。

- 区间是重采样百分位区间，**不是显著性检验**；四格作为完整 family 一并报告，未做多重性校正，理由与后续若入稿的要求见 `03-metrics.md` 第 5 节。
- 不能写成"证明了 C 与 B 等价"：区间跨 0 只说明这套数据与这个口径下看不出方向，精度不足以排除中小差异（区间半宽 0.013–0.024 AP）。

## 3. 1,000 次与 20,000 次相比，区间端点有移动、点估计不变

点估计一个也没动（由五折点估计决定，与重采样次数无关）。区间宽度变化 −0.9% ~ +8.1%，最大的是"验证集自选 α · S1_30"（0.024722 → 0.026735），其上下限分别向两侧移动。本轮没有做密度或尾部误差分析，不解释这个差异的原因。

- 来源：`exports/secom_boot20k_summary.json` 与归档 `secom_summary.json` 的 `ci95` 对照，见 `03-metrics.md` 第 3 节。

## 4. 逐折噪声主导，不能拿单折说话

五折点估计符号不一致：fixed S0 为 −0.003/+0.014/−0.005/+0.031/+0.020；selected S1_30 五折全负但幅度从 −0.0011 到 −0.0307 差近 30 倍。单折 95% 区间宽度最大达 0.17 AP。

- 来源：`exports/secom_boot20k_summary.json` 的 `per_fold` 与 `per_fold_ci95`。
- 影响：任何"某一折显示 C 更差/更好"的表述都不能作为证据；主结果只能看跨折汇总。

## 限制与未决项

1. **这批材料是本次重跑，不是历史 20,000 次的原件。** 历史那批的数值无法核对，也不应被本结果替换而不作说明。
2. 随机流与原 1,000 次运行同源（`20261101 + 折号`），所以"汇总一致"证明的是口径相同，**不构成独立复现**。
3. 只覆盖 `C025/B025/C_selected/B_selected` 四个配置；`C050/C100/B050/B100`、`M3/M4` 与 S1_10、`*_val__*` 不在本轮范围。
4. 若要把 20,000 次写进稿件：必须同时给出脚本、输入哈希、随机种子与"本次重跑"的标注；不能引用为原始结果。
5. 未核：历史那批若存在，其 seed 是否也是 `20261101`、是否为 20,000 次、是否同一估计量——无从核对，不做推断。
