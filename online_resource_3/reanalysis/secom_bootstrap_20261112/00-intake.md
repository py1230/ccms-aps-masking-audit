## 指标与口径（冻结，不允许在重跑中调整）

- 指标：average precision（AP），以**权重化 AP**实现（`wap`）：先按概率降序稳定排序，按并列概率分组，用重采样计数当权重。
- 重采样：**折内按标签分层**，正类抽 `len(pos)` 次、负类抽 `len(neg)` 次（有放回），拼成该次 draw 的计数向量；五折各自独立抽样。
- 随机流：每折 `np.random.default_rng(20261101 + i)`，i 为折号；逐 draw 顺序消耗。该构造下本轮与归档 1,000 次运行**使用同一条随机流（同种子、同消耗顺序）**，这是本轮一致性校验的基础；但它只能证明口径相同，不等于已经核对过历史逐次数组。
- 逐次统计量：每次 draw 先算该折各条件下的 `wap(C) − wap(B)`，S1_30 取三个遮蔽种子（101/202/303）的均值；再对五折取均值，得到该 draw 的 ΔAP。
- 汇总：`delta_mean` = 五折点估计的均值；`ci95` = 逐次 ΔAP 的 2.5/97.5 分位。
- 四格（完整 family，全部报告，不挑）：`fixed_C-B`（α 固定 0.25）× {S0, S1_30}、`selected_C-B`（验证集自选 α）× {S0, S1_30}。
