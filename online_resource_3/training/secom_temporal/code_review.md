## 已核对的实现链路

1. 输入冻结：独立计算 freeze.json 所列七个文件的 SHA-256，全部匹配。run_temporal.py 在加载输入阶段重复校验，结果目录已存在则拒绝覆盖。
2. 时间划分：独立按时间戳稳定排序，验证所有内层训练为最早连续前缀、验证为紧随其后的连续区段、完整外层训练为两者并集、测试为随后连续区段。各数组内无重复，索引均合法。内层 max(train_time)<min(validation_time)，外层 max(past_time)<min(test_time)，未发现同时间戳跨界。
3. 候选选择：各 C/B 臂都遍历 alpha=[0,0.25,0.5,1]；alpha=0 映射到共享 M3，作为普通候选，满足自己的 S0 容差。按四输入最差 AP 最大化并在精确并列时选较小 alpha；选择文件在外层拟合和测试预测前写出。
4. 预处理：当前 stage 的中位数、类别缺失率和类别计数只使用 train_rows。选择阶段使用内层训练；外层阶段重新估计完整过去训练数据上的预处理。全空列填零，590 列均保留并追加590个遮蔽后缺失指示变量。未使用验证或未来测试拟合预处理。
5. 模型与重拟合：early_stopping=False；每个 stage 拟合一个共享零干预基线与六个非零配置各三个成员，共19次。三窗口选择/重拟合两阶段共114次，外层重拟合使用全部当前过去数据。
6. C/B 预算：算子概率实现与论文定义一致，C/B 同种子生成同形状的均匀随机数；仅删除原本可见单元格。每次 stage 显式断言 C/B 期望逐列删除数匹配，另保存逐列、逐类、逐行实际删除数。实际计数不要求相等。
7. 评价：每个非零配置先在逐样本层面平均三个成员概率，再为每个 S0 / S1 输入单独计算 AP。测试 S1 30% 的三个重复 AP 随后等权平均。选择压力为10%，测试压力为30%，二者符合冻结协议；未用测试分数重新选择。
8. 产物：保存每次拟合的 joblib 模型、训练行索引、预处理、训练掩码；保存各成员及各配置集合的全部逐样本预测、原始行号、标签、各输入 AP、候选分数和选择记录。完成时保存摘要和文件哈希清单。模型生成所需的评价掩码可由冻结代码、固定种子及原始输入重建。
