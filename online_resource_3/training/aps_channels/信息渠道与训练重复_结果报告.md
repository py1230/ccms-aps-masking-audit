# APS 信息渠道与条件训练随机性重复结果

本轮从原始数据完成855次正式新拟合并通过独立产物核验，另有3次小规模接口检查，不计入正式结果。三渠道使用同样原始行、预处理、训练和评价掩码；每一重复重新拟合并重新选择。原 v2.4 与既有 APS 重跑产物未覆盖。

## 设计与统计口径

三渠道为 M2（170个插补值）、M3（170个插补值加170个当前缺失指示）、MO（仅170个当前缺失指示）。每渠道15个重复×划分单元，各19个模型。各渠道以自身无新增遮蔽基线选参。所有非零候选先平均三模型概率，再计算AP。

三组模型种子2026/2027/2028，掩码种子组19107–19109、29107–29109、39107–39109；五个划分11/22/33/44/55固定。使用Python3.12.15、NumPy2.5.4、scikit-learn1.9.1，完整环境见environment_packages.txt。

这是固定原始样本、外层划分及评价压力的条件训练随机性重复。模型与掩码种子共同变化，不能分别归因；未做训练样本重抽。三组范围不是置信区间，15单元不能作为15独立数据集。官方测试此前已接触，实验属于回顾性探索。

## α 选择

M2 的 C/B 选择 α=0 的次数分别为 2/15 和 0/15；M3 的 C/B 选择 α=0 的次数分别为 15/15 和 0/15；MO 的 C/B 选择 α=0 的次数分别为 15/15 和 7/15。

M3、MO 的 C 在全部15个单元均选择零，因此选择后的 C 就是本渠道的无新增遮蔽基线。其与 B 的选择后差值不能解释成 C 实施非零遮蔽造成的损失；它还反映 B 相对该基线的表现。

## 核验范围

独立实现重新读取原始 CSV，重建三渠道与全部掩码并重载 855 个模型，核对 22230 个单模型预测数组、8190 个 AP 单元及 90 项选择。重载预测的最大绝对误差为 0，AP 独立复算最大误差为 4.44e-16，均在运行前固定容差内。15 组重复×划分的原始行、预处理与训练及评价掩码跨渠道一致。该核验检查本次保存产物与实现的一致性，不是另一批独立训练或历史来源认证。

最大误差：`{"prediction": 0.0, "ensemble": 0.0, "ap": 4.440892098500626e-16, "expected_budget": 5.5706550483591855e-12, "selection_score": 4.440892098500626e-16, "summary": 4.440892098500626e-16}`。

额外基线对照显示，第一组M3无干预模型的130组验证/测试预测与上一轮匹配环境M3逐元素一致，最大差为0（audit/baseline_anchor_check.json）。该检查只覆盖这个未改变种子的基线，不把新遮蔽候选要求为旧数值，也不证明历史来源。

独立核验代码不导入训练脚本的渠道转换、掩码、AP与选择函数。三份渠道核验报告分别记录代码指纹，再由--combine核对跨渠道指纹。核验由同一会话的另一助手和独立代码路径完成；不是盲审、跨模型研究或期刊同行评审。

## 可支持与不可支持的解释

固定强度、官方测试 S1 30% 下，三个重复组的五划分均值方向分别为：M2 为 2/3 负向、1/3 正向；M3 为 3/3 负向、0/3 正向；MO 为 3/3 负向、0/3 正向。

M2 的三组均值依次为 -0.0167、-0.0168、+0.0114，固定强度比较随随机组变号，不能把 M3 的结果不加限定地外推至不追加显式指示的 M2。此处的组间范围为描述性范围，不是检验或置信区间。不同渠道的零干预选择次数也不同，历史主模型的“C 五次均选择 α=0”不代表全部渠道的选择行为。

选择结果表明，完整程序必须结合具体渠道、随机组与验证规则解释；固定非零强度的差值不能代替选择后的结果。M2 的中位数填充值仍可能暴露缺失位置，而渠道变化同时改变模型输入表示及可拟合函数。上述对照用于定位当前流程中的表现差异，不能独立证明纯类别分配机制或显式缺失指示的因果贡献。三组重复也不足以给出总体尾部概率或完整训练不确定性。

本轮补上了统一渠道对照与固定样本条件下的训练随机性重复。它未完成A5双边际匹配、独立模拟种子扩展、训练样本重抽或跨工厂验证，也未解决历史协议、脚本来源与作者声明。旧条件Bootstrap区间继续仅对应旧预测，不移用到本轮。

## 文件映射

- PROTOCOL.md、config.json、freeze.json：运行前方案与指纹。
- run_results/{M2,M3,MO}/：全部模型、单模型与集成预测、掩码、诊断及日志。
- verification.json 与 verification_{M2,M3,MO}.json：独立产物核验和跨渠道配对检查。
- ap_by_unit.csv、selections.csv、contrasts_by_unit.csv：全部单元AP、选择及配对差。
- contrasts_by_repeat.csv、descriptive_summary.csv/json：先五划分后重复组的描述性汇总。
- paired_channel_contrasts.csv：各渠道C/B效应差的配对描述，不作因果解释。
- README.md、make_repeat.py：新目录中的重复执行说明。
