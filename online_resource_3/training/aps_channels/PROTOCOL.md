# APS 信息渠道对照与条件训练随机性重复

## Material Passport

- artifact_type: code_experiment_protocol
- mode: run
- data_access_level: raw
- status: protocol fixed before formal execution
- purpose: 在相同数据划分、遮蔽与模型设置下比较信息渠道，并重复掩码抽取、拟合与参数选择。

本研究为回顾性探索实验，已接触历史 APS 测试结果；本协议仅为本次运行前固定，不是历史预注册。不得根据本轮测试结果调种子、删配置或改方案。

## 设计与信息渠道

采用原始 APS 60,000 行训练 CSV 与 16,000 行官方测试 CSV，以及已核验的五组历史行索引。每组训练42,000/验证9,000/预留9,000；预留子集本次不用。保持170列，原始训练部分拟合中位数，全空列置零，所有臂共用该中位数。

- M2：170个中位数插补特征，无显式缺失指示。插补值仍可能间接暴露缺失位置。
- M3：170个插补特征与170个当前缺失指示拼接。
- MO：仅170个当前缺失指示，不输入数值特征。

每个渠道的指示都从原始缺失与新增遮蔽合成后的矩阵构建，训练和测试遵循同一规则。三渠道对同一重复组、划分、臂、alpha、mask seed 使用逐元素相同的新增训练掩码，评价压力输入也完全相同。渠道变化同时改变模型输入表示及可拟合函数，不能把跨渠道差值解释成纯粹信息通路的因果效应。

## 重复和候选

三个预先固定重复组：R1 mask seeds19107–19109/model2026；R2 mask seeds29107–29109/model2027；R3 mask seeds39107–39109/model2028。每组对五个既定划分重新生成遮蔽、重新拟合所有模型与重新选择alpha。模型种子在同重复组所有渠道/候选之间配对。

每重复×划分×渠道：一个alpha0的BASE模型，加C/B各alpha∈{.25,.5,1}各三个掩码模型，共19个；合计3×5×3×19=855次正式拟合。每次非零候选先平均三模型概率再算AP；BASE只有一个模型，同种子重复拟合三次不增加随机性。

C/B算子复用匹配环境APS重跑代码；相同alpha的C/B期望逐列预算相等但实际抽样删除量不必相同。无A3/A4/A5，本轮不扩张这些机制解释。

## 模型与选参

保持历史版本匹配环境，Python3.12.15、NumPy2.5.4、sklearn1.9.1。HGB参数完整列于config.json，100次最大迭代，early_stopping=auto，validation_fraction=.1；random_state按重复组变化，因此模型内部早停划分也是本次算法随机性的一部分。外层中位数及缺失率使用42,000训练行；内层早停并不构成独立外部验证。未为不同渠道调参。

只使用外层验证S0和三个S1 10%输入选参。alpha0是普通候选；相对各渠道/重复/划分自身BASE，S0 AP损失≤.01为可行；选最差四输入AP最高者；完全数值并列选较小alpha。C/B分别选择。先保存选择记录，再生成正式测试预测；选后不重拟合，继续使用42,000训练行模型。

## 评价与分析

S0、S1 10%三个、S1 30%三个、S2三个、S3三个共13输入，完全沿用归档build_eval_inputs函数，不读取评价标签生成输入；跨所有渠道和重复固定。每个压力输入先单独计算AP，之后对同类三个输入等权平均，再对五个划分等权平均。

主要比较：固定alpha=.25下C−B、C−BASE、B−BASE；另报完整选择后C−B、C−BASE、B−BASE及选择频率。报告各重复的五划分均值，再给三个重复的均值、最小和最大值；逐划分结果完整保留。可描述跨渠道差异，不将其当作纯机制识别。均值范围不是置信区间；不使用旧条件Bootstrap区间，也不对15个重复×划分单元做独立数据集式检验。

这是固定数据/固定外层划分/固定评价压力下的条件训练随机性重复。它覆盖掩码、模型拟合、内部早停划分及选择的联合随机性，但未包含训练样本重新抽样、外层切分变化、压力种子变化、外部数据变化，也不分别识别各随机因素。三组不足以估计尾部概率或证明稳定性/等效性。

## 保存、核验与资源

保存原始索引、所有掩码、预处理、855个模型、全部单模型与集成概率、每条件AP、全部选择候选、实际早停迭代数、运行日志及版本。配置/输入/代码在运行前冻结SHA256；输入不改动，既有结果拒绝覆盖。接口smoke单列，不以其AP调设计。独立核验由另一助手实现，不复用runner渠道构建/选择函数；重建掩码、逐模型重载预测、复算AP、选择及跨渠道一致性。

机器8逻辑核/8GB RAM，可用空间约172GiB。三渠道最多三进程，每个2线程，评价矩阵按需构建。预计3–5GB保存空间、约25–40分钟墙钟（估计非承诺）。进程与日志持续监控；失败保留现场及failure.json，修复须记录并另开输出，不覆盖失败结果。科学配置变化须新版本冻结。
