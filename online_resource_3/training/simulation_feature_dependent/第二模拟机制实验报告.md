# 第二模拟机制：完整运行及核验报告

本轮在用户授权后按本地预先冻结协议完成30个新种子（701–730）、600个正式模型；接口种子99002的20个模型不进入推断。没有按效果扩样、替换种子或重试。冻结文件和原始产物保持不变。本报告生成于全部正式运行及另行实现的核验通过之后。

## 设计与解释范围

完整数据为8000×20，标签真信号仍为1.2(X0+X1+X2)；60/20/20类别分层划分。第二机制把缺失概率设为logistic(a_yj(m)+clip(X19,−4,4))，以80次二分使每类每列平均缺失概率达到预定q_yj(m)。X19始终观测、并不进入真实标签方程。训练与源验证m=1，九个目标m从1到−1共享每种子完整目标X/Y和基础U。保存的最高类别均值校准误差为4.44e-16。

该设计在条件于生成矩阵时保留预定每类期望缺失率及总体期望缺失率，改变可观测协变量依赖和联合掩码结构；实际缺失数仍随机。每个子集的Y仅用于模拟缺失生成与评价，预测函数不读取Y。源验证完成并保存选择后才构造目标输入、预测；目标结果不参与参数选择。

这是“标签与已观测协变量共同驱动的缺失”，不无条件称MAR。辅助变量可能帮助模型理解缺失掩码，其始终观测的规定亦有别于旧生成器。因此本次结果是第二机制下的独立检验，不能把与旧30种子结果之差当作机制变化的因果效应，也不合并旧新种子。

## 主要和逐点结果

预定主要估计量是每种子九点等权固定α=0.25 C−B的平均，再在30种子间取均值：**+0.001361 [-0.001423, +0.004145]**；种子间SD=0.007456，20,000次完整种子向量Bootstrap的逐点百分位区间为[-0.001216, +0.004033]。t区间半宽=0.002784，预定0.005精度目标达到。该目标不是等效界限；平均值接近零不能证明各目标条件等效。

固定强度在源机制一致点m=1的差为-0.018152，在m=0为+0.006079，m=−1为+0.003371，方向随目标缺失条件而变。九点均值会掩盖这种方向差异。选择后的九点中有0点通过同一Holm家族校正，不能把固定强度某些条件的收益直接转述为完整选择程序的普遍收益。

源验证选择频数（α=0、0.25、0.5、1）：C为[28, 2, 0, 0]，B为[26, 4, 0, 0]。α=0共享M3，选择后不重拟合；0.01的源域容忍阈值为工程规则。

## 留存、成本与核验

每种子目录留存完整X/Y、分层索引、原始U、自然与追加掩码、每行/列/类别×列删除量、20个模型、全部源验证及九点目标概率、候选分数、选择、预处理、参数和事件日志。模型文件是本轮本地生成的可信文件。`manifest.json`记录逐种子文件SHA256，`freeze.json`记录运行前冻结文件SHA256。

自然缺失的概率矩阵另以派生副本保存在`analysis/generation_probabilities/`：这些副本在正式核验后由已存X、类别q和截距重建，没有重新抽样或训练；全部330个自然掩码均由其与原U阈值重建吻合。输入/输出哈希及来源在`analysis/generation_probability_provenance.json`。

另行实现的核验不导入runner或分析代码，以Brent求根复算缺失机制并逐掩码核对，重载600个正式模型、重算7800组单模型概率、3900组集成概率、3900项AP和60次选择。概率最大绝对差=0，集成概率差=0，分组并列AP差=2.22e-16。20,000次配对Bootstrap索引、主要/次要区间和18项Holm结果均复算通过。该核验与实验在同一会话完成，不称独立团队复现实验，不认证历史训练来源。

正式启动器实测历时285.32秒；600个模型记录阶段耗时之和为194.38秒。后者包括掩码准备、拟合、模型序列化和源验证预测/保存，**不是纯拟合耗时**。单工作进程、最多2个本地线程；并行的其他实验可能影响耗时，不据此跨运行排名。峰值内存未记录。接口检查、冻结、分析和独立核验耗时不在正式启动器历时内。
